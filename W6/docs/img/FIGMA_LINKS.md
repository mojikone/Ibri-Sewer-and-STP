## About the titles on each group

FigJam draws each group as a *section*, and a section carries its name on the small tab at
its top-left corner. That name is real — it is stored with the file and shows in Figma's
layers panel — but **an exported PNG or SVG does not draw it**, which is why the tab looks
like an empty box in the pictures. So the titles are not written there. Each group instead
has a proper dark title box as its first item, which shows everywhere: on the board, in the
export, and in Word.
