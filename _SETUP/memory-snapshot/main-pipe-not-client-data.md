`Hydraulic/SHP/Main Pipe/Main Pipe.shp` is the engineer's placed trunk, an INPUT to the design engine. It is not from Nama Water
Services. Do not draw it on report maps that present the study area or the data received, and never describe it as client data.

**Why:** on 2026-09-17 I proposed the main pipe on the topography map of the concept report's study-area section; the engineer:
"the main pipe is not from client. Do not show it". A client reads everything on a descriptive map as given fact.

**How to apply:** descriptive and data maps carry client data and public data only (boundary, settlements, plots, meters, terrain,
wadis, roads as supplied, hazard with its source). The main pipe belongs only where the design itself is presented, labelled as
proposed. Related: [[report-format-preferences]], [[asset-gis-holds-proposals]].
