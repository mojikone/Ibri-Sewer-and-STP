**Why:** user reviews under time pressure; the exec summary is what actually gets read (and shown to others).

**How to apply:** write it LAST (after the body is settled), place it FIRST; carry the real numbers and conclusions, not process talk; keep the plain colleague register per [[plain-wording-not-literary]] — unless the user says the report goes to the client, then client-facing style (rule 5).
