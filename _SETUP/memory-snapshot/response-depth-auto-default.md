Default to **AUTO**: no length ceiling, judge the reply by what the content
needs. Always open with a **bold headline line that stands alone**, so the user
can read one line and stop, or read on and lose nothing.

`L1`–`L5` apply only when invoked, and they **nest** — each adds to the one
below, every one opens with the L1 line:

- **L1** the answer · **L2** + numbers and next step · **L3** + why and the
  caveat that changes a decision · **L4** + derivation, sources, what was
  checked · **L5** + the working, alternatives rejected, dead ends.

Sticky within a chat, released by `auto`/`L0`. Not sticky across chats unless
written as a standing default in `CLAUDE.md` rule 13. Modifiers: `why`,
`show me`. At L4/L5 put the detail in a file and give a one-line pointer.

**Why:** the user repeatedly asked for shorter replies — roughly a dozen times
in one session, never once for more — but said explicitly they did *not* want a
level they set casually to cost them a substantive answer. So the fix is not a
lower default; it is a headline they can stop at, with everything still beneath
it. Their colleague's five-level scheme was the starting point; it defined
levels by length rather than by content, was substitutive rather than nesting,
and had no default that releases the constraint.

**How to apply:** lead with the headline in every reply. When a level trims
something real, say where the full version lives. Related:
[[plain-wording-not-literary]], [[report-exec-summary-priority]].
